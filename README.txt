SMV LANGUAGE ACADEMY WEBSITE
============================

Files:
- index.html  -> main website
- style.css   -> all design / responsive layout
- script.js   -> Sinhala/English switch, mobile menu, WhatsApp form
- assets/     -> your supplied SMV logo images

How to use:
1. Keep index.html, style.css, script.js and assets folder together.
2. Double-click index.html to preview the website locally.
3. Upload the whole folder to your web hosting / cPanel public_html.

WhatsApp:
The site uses 077 257 2396 (Sri Lanka +94 format) and opens WhatsApp with a pre-filled message.

YouTube:
The YouTube buttons point to https://www.youtube.com/@sudumahathayavibes

No backend/database is included. The inquiry form works by opening WhatsApp from the visitor's device.
